# Azure DevOps Test Case Context: #2001 - Verify CME Corporate Account Creation

**State**: Ready  
**URL**: https://dev.azure.com/enterprise-org/CoreBanking-CME/_workitems/edit/2001  

## Description
End-to-end verification of corporate onboarding flow via CME web portal.

## Execution Steps (3)
1. **Step**: Log in using StandardUser credentials and navigate to CME Account module
   *Expected*: User lands on CME Account Management home view with Active status

2. **Step**: Click "+ New Corporate Customer" button and enter valid company registration details
   *Expected*: Form validates company fields, tax ID, and address correctly

3. **Step**: Select Risk Level "Standard" and click Submit
   *Expected*: System returns generated Account Reference ID with Pending Approval status
