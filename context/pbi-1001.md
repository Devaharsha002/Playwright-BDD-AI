# Azure DevOps PBI Context: #1001 - Customer Onboarding & CME Profile Validation

**State**: Active  
**URL**: https://dev.azure.com/enterprise-org/CoreBanking-CME/_workitems/edit/1001  

## User Story & Description
As a CME Operations Officer, I need to create and validate commercial corporate accounts so that onboarding compliance criteria are verified.

## Acceptance Criteria
Corporate account number must follow ISO-13616 standard formatting.

Primary contact email must belong to an authorized enterprise domain.

Risk rating must default to "Medium" unless high-risk jurisdiction flags are triggered.

Account status must transition from "Pending" to "Approved" upon validation.
